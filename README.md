# make-md

A Typora-style desktop Markdown editor built with Tauri, Vue 3, and ProseMirror.

## Features

- Live Markdown rendering with rich editing
- Local file open/save with recent document tracking
- Autosave and crash recovery
- Syntax highlighting for code blocks
- Cross-platform (macOS, Windows, Linux)

## Development

```bash
pnpm install
pnpm tauri dev
```

## Testing

```bash
pnpm test
```

## Build

```bash
pnpm tauri build
```
