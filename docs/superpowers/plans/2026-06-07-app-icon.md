# App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create and ship a new monochrome `make-md` application icon based on the approved document-first `M` concept, then replace the Tauri icon asset set.

**Architecture:** Build a deterministic SVG master in-repo instead of relying on opaque generated artwork. Rasterize the SVG to a square PNG master, regenerate platform icon files from that master with the Tauri CLI, and verify the final assets at representative sizes.

**Tech Stack:** SVG, shell image tooling on macOS, Tauri CLI icon generation, Git

---

## File Structure

- Create: `src-tauri/icons/icon-master.svg` for the editable source of truth
- Create: `src-tauri/icons/icon-master.png` for the raster master used by Tauri icon generation
- Modify: `src-tauri/icons/*` generated icon assets replaced from the new master
- Modify: `.gitignore` to ignore local brainstorming artifacts
- Reference: `docs/superpowers/specs/2026-06-07-app-icon-design.md`
